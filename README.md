# The Garden of Verses 🌿

A poetry collection web app — beautifully animated, seasonal, and meditative.

## Getting Started

### Prerequisites
- Node.js (v16 or newer)
- npm

### Install & Run

```bash
npm install
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000).

### Build for Production

```bash
npm run build
```

Outputs a production-ready build to the `build/` folder.

## Features

- **Animated intro** — words bloom onto the screen one by one
- **Four seasons** — Spring, Summer, Autumn, Winter, each with its own colour palette
- **Word-by-word poem reveal** — tap any poem card to watch it unfurl
- **Scroll animations** — sections fade in as you scroll
- **Responsive** — works on mobile and desktop

## Poems included

Works by Oh Ae-sun, Rabindranath Tagore, Kabir, Pablo Neruda, Li Bai, Du Fu,
Rūmī, Ryōkan, Mary Oliver, Wisława Szymborska, Yehuda Amichai, and John Keating
(Robin Williams, *Dead Poets Society*).
